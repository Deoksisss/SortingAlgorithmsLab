## Правила коммитов

- Conventional Commits на английском.
- Один логический этап — один коммит.
- Перед коммитом: сборка, относящиеся тесты, просмотр diff.
- После коммита: `git push origin main` и проверка успеха.
- Не переписывать опубликованную историю, не использовать force push.
