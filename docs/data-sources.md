# Источники данных о странах

Файл `src/SortingLab.App/Data/countries.csv` содержит 195 независимых государств и пять столбцов:

| Столбец | Содержание |
|---|---|
| `Страна` | краткое русское название |
| `Континент` | Европа, Азия, Африка, Северная Америка, Южная Америка, Австралия и Океания |
| `Столица` | русское название столицы |
| `Площадь` | площадь, км² |
| `Население` | численность населения, человек |

## Источники

1. **Список независимых государств и классификация регионов** — проект `datasets/country-codes` (Open Knowledge Foundation):
   <https://github.com/datasets/country-codes>
   Использованы поле `is_independent = Yes`, коды ISO 3166-1, русские краткие названия (`UNTERM Russian Short`), регион и субрегион.

2. **Численность населения (2023)** — Всемирный банк, индикатор `SP.POP.TOTL`:
   <https://api.worldbank.org/v2/country/all/indicator/SP.POP.TOTL?date=2023&format=json>

3. **Площадь территории (2022)** — Всемирный банк, индикатор `AG.SRF.TOTL.K2` (Surface area, sq. km):
   <https://api.worldbank.org/v2/country/all/indicator/AG.SRF.TOTL.K2?date=2022&format=json>

4. **Русские названия столиц** — Wikidata, свойство `P36` (capital), метки на русском языке; выбор столицы согласован с полем `Capital` из `country-codes`. Запрос выполнен через SPARQL-эндпоинт:
   <https://query.wikidata.org/>

5. **Тайвань** отсутствует в индикаторах Всемирного банка. Для него использованы значения Wikidata (Q865): площадь 36 197 км², население 23 262 544 человека. Значения приведены как есть из указанного источника.

## Обработка

- Население округлено до целых.
- Площадь округлена до одного знака после запятой (в CSV — с точкой, независимо от локали).
- Континент получен из региона/субрегиона `country-codes`:
  - `Europe` → Европа;
  - `Asia` → Азия;
  - `Africa` → Африка;
  - `Oceania` → Австралия и Океания;
  - `Americas` + `South America` → Южная Америка;
  - остальные `Americas` → Северная Америка.
- Спорные и зависимые территории в набор не включены; используются государства с `is_independent = Yes`.
- Данные являются снимком на момент подготовки проекта и могут отличаться от более поздних публикаций.
