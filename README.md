# Практическое задание №4 — Алгоритмы сортировки

Настольное приложение на **C# / Avalonia UI**, объединяющее три практических задания по дисциплине «Алгоритмы и структуры данных»:

1. **Внутренняя сортировка** — Odd-Even Sort и Tournament Sort с пошаговой визуализацией.
2. **Внешняя сортировка** — естественное слияние (Natural Merge Sort) с реальными временными файлами.
3. **Сортировка текста и сравнение алгоритмов** — QuickSort и Unicode Radix Sort, подсчёт частоты слов и замеры производительности.

Интерфейс полностью на русском языке, светлая тема, единый современный стиль.

## Технологии

- C# 11, .NET 8
- Avalonia UI 11.3
- CommunityToolkit.Mvvm
- xUnit для автоматических тестов
- Git / GitHub

## Быстрый запуск

```powershell
dotnet restore
dotnet build -c Release
dotnet test -c Release
dotnet run --project src/SortingLab.App/SortingLab.App.csproj -c Release
```

## Реализованные возможности

- Генерация массива, ручной ввод, настройка диапазона и размера.
- Пошаговое выполнение с паузой, продолжением, ручным шагом, остановкой и сбросом.
- Регулировка скорости во время демонстрации.
- Столбчатая диаграмма, таблица элементов, журнал операций и понятные пояснения.
- Отдельная визуализация турнирного дерева.
- Загрузка CSV, выбор ключевого столбца, типа данных, направления и фильтра по континенту.
- Настоящая внешняя сортировка через временные файлы и естественные серии.
- Сохранение результата в CSV и открытие папки с результатом.
- Загрузка или генерация текста, извлечение слов, подсчёт частот, поиск по словам.
- Сравнительные эксперименты QuickSort / Radix Sort с таблицей и графиком.
